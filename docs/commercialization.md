# Commercialization
The product is sold as software as a service. A retailer signs up as an organisation, its staff log in with roles, and the organisation pays, not each employee. That is why prices follow returns, API usage and stores instead of seats.

## Target customers
| Customer | Their pain | What we lead with |
| --- | --- | --- |
| E-commerce companies | High return volume, size and fit, damage in transit | Bulk mode, per-product investigation |
| Supermarkets | Low value per return, batch and expiry problems, many stores | Pay as you go, supplier and batch watch |
| Electronics resellers | Defects, high order values, supplier disputes | Batch findings, human-review value threshold |
| Fashion resellers | Size and fit, wearing then returning items | Product investigation, abuse signals |
| Large retail chains | Many stores, many suppliers, audit needs | Enterprise tier, private cloud, per-store metrics |
